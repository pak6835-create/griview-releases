# 그리뷰 (GriView)

웹툰 원고(PSD · PSB · CLIP · 그림)를 폴더째 빠르게 보고, 비교하고, 피드백을 남기는 윈도우 프로그램입니다. — 모모드롭

## 받기

**[최신 설치 파일 받기 →](https://github.com/pak6835-create/griview-releases/releases/latest)**
(`GriViewSetup-버전.exe`를 받아 실행하세요)

- 설치할 때 «Windows의 PC 보호» 창이 뜨면 **추가 정보 → 실행**을 누르세요.
- 처음 3개월은 모든 기능을 무료로 씁니다. 그 뒤에도 보기 · 비교 · 받은 피드백 보기는 무료입니다.
- 설치한 그리뷰는 새 버전이 나오면 알아서 알려 주고 받습니다.

## 이 저장소

설치 파일과 자동 업데이트 파일만 올려 두는 곳입니다(프로그램 소스 코드는 없습니다).
업데이트 파일은 모모드롭 서명이 맞아야만 그리뷰가 받습니다.
